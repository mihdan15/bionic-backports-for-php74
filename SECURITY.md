# Security policy

## Scope

Report problems in how these packages are built or published, for example a missing or
wrong patch, a release that does not match its pin, or a compromised workflow or release.

Vulnerabilities in PHP itself belong to the PHP project
([php/php-src security](https://github.com/php/php-src/security)). Problems in Sury's packaging
belong to [deb.sury.org](https://deb.sury.org).

## Reporting

Use GitHub's private vulnerability reporting: the **Security** tab, then
**Report a vulnerability**. Please don't open a public issue for a security problem.

## Support

Only the newest release is supported, on a best-effort basis. PHP 7.4 and Ubuntu 18.04 are
end-of-life; plan an upgrade.
